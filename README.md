## 📌Sobre o projeto
Este projeto apresenta um site desenvolvido sobre o jogo Minecraft, abordando sua história, características e evolução ao longo dos anos. O objetivo é reunir as principais informações sobre o jogo de forma visual, organizada e interativa.

## 📄Páginas do site
### 1. Página inicial
Apresenta o projeto e uma introdução sobre o Minecraft, além de permitir a navegação para as demais páginas.
### 2. História do minecraft
Apresenta a história do minecraft, desde seu desenvolvimento inicial até a popularização e evolução ao longo dos anos. Também contém curiosidades sobre o game.
### 3. Modos de jogo
A página apresenta os modos de jogo do Minecraft, orientando o usuário sobre suas características, objetivos e diferenças, além de indicar o modo mais adequado ao seu perfil. Também reúne estatísticas, dicas, curiosidades, FAQ e a evolução dos modos ao longo do tempo.
### 4. Biomas
Apresenta os diferentes biomas encontrados no Minecraft, destacando suas características, ambientes, recursos e criaturas. 
### 5. Dimensões
Apresenta um guia sobre dimensões possíveis de se encontrar no minecraft e como acessa-las.
### 6. Mobs
Apresnta um guia completo de mobs do Minecraft.

## ▶️ Como abrir o site?
### 1. Acessando o site
O site pode ser acessado diretamente pelo link público abaixo:
*link do site:* https://paolapietropoli.github.io/site-minecraft/
Basta clicar no link para abrir o site pelo navegador.

### 2. Acessando o projeto pelo GitHub
Caso seja necessário baixar ou clonar o projeto, acesse o nosso repositório no GitHub:
*link do github:* https://github.com/paolapietropoli/site-minecraft
Para clonar o projeto:

1.Abra o repositório no GitHub.
2.Clique no botão **Code**.
3.Copie o link que aparecer em **HTTPS**.
4.Abra o Visual Studio Code.
5.Abra o terminal.
6.Digite:
* git clone https://github.com/paolapietropoli/site-minecraft

Pressione Enter.
Abra a pasta do projeto no Visual Studio Code.
Abra o arquivo **index.html** para visualizar o site.
Abra o arquivo em um navegador, como Google Chrome, Microsoft Edge ou Firefox.
